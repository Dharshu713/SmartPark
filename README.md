Smart Park — Milestone 1
Premium responsive landing page prototype built with HTML, CSS and vanilla JavaScript.
Files
- index.html — page structure and content
- style.css — responsive graphite, ivory and champagne-gold styling
- script.js — mobile navigation, demo parking search, EV preselection and active navigation
Run locally
Open index.html in a browser, or use the VS Code Live Server extension.
Prototype limitations
The parking search is a front-end demonstration. It does not query live parking availability, reserve spaces, process payments, or connect to sensors. Those functions are planned for later milestones.
